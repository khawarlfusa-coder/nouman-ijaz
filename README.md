## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/khawarlfusa-coder/nouman-ijaz.git

# Navigate into project directory
cd nouman-ijaz

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open `http://localhost:3000` (or `http://localhost:5173`) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
